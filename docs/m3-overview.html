一、三级关系（ADR-8）

A 全局只读

系统内置工具 / 技能 / Agent
  • 全实例共享，用户不可改 origin
  • 来源：系统内置市场（OH-Plugins）
  • 对应现有 PluginMarketplace 远程源

B fork 私有

复制为我的副本后改
  • 系统保留 origin，副本存 UserHome
  • 用户可在自己引擎内自由改
  • 对应 user_assets 私有层

C 用户间分享

发布到 Sharing Market
  • 同实例全员、免审核（靠沙箱兜底）
  • SystemDB shared_assets 索引
  • 他人安装 = 一份私有 fork 副本
